Importing OPML into Podcast Clients
AntennaPod (Android)
Subscriptions → + (Add Podcast) → Import / Export → OPML Import
Pocket Casts (iOS & Android)
Profile → Settings → Storage & Data Use → Import OPML
Overcast (iOS)
Settings → Nitpicky Details → Import OPML
Apple Podcasts (macOS)
File menu → Add Show by URL... or drag .opml onto the Podcasts window
Browser Extension
Chrome, Edge, Brave, Opera, Vivaldi
Download the extension and unzip it. Open chrome://extensions (Edge: edge://extensions), turn on Developer mode, click Load unpacked, and pick the unzipped podcast-rescue-extension folder.
Firefox
Download the Firefox extension and unzip it. Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and pick manifest.json inside the folder. Firefox removes it on restart, so repeat when needed.
Safari
Safari only loads signed extensions, so use the Rescue Library (Bookmark) button instead: drag it to your bookmarks bar, open your Podbean page, and click it.
After installing
Reload this page, paste your Podbean profile link, and click Fetch & Ingest. A new tab opens, syncs as the account you are logged in to, and sends the shows back here.
